# AL_HWatchers

[English version](README.md)

**AmanatsuLocation** のHシーンを、ほかの女の子たちが見物するようになる BepInEx 6 (IL2CPP) プラグインです。

Hが始まると、同じマップにいる女の子たちが二人のまわりに集まって見物します。シーンが進むにつれて反応し、興奮し、オナニーを始め、女の子同士で絡み、最後にはぶっかけにも加わります。見物している子を、シーンの女の子と入れ替えることもできます。

## 機能

- **見物:** マップにいる女の子がシーンの方を向いて見物します。シーンの人物、壁、カメラの邪魔にならない場所に立ちます。ベッドでのHでは、ベッドのまわりの床に立ちます。
- **反応:** 驚いたリアクション、待機ポーズ、表情、声が、それぞれの興奮度に合わせて変わります。
- **オナニー:** 興奮した子は、立ったまま、しゃがんで、または寝転んでオナニーします。この機能は任意で、Aicomi が必要です（下記参照）。
- **カップル:** ゲーム内でカップルになっている二人は、どちらも興奮すると女の子同士で絡みます（貝合わせ または 69）。壁や家具、カメラを避けて床の上で行います。
- **ぶっかけ:** 男性が女の子にかけるとき、見物している子たちもそばにひざまずいて一緒にかけられます。
- **女の子の入れ替え:** 見物している子を、シーンにいる女の子と入れ替えられます。体、服、衣装、声、疲れた状態も引き継がれ、ゲームの服メニューもそのまま使えます。入れ替えられた子は見物に回ります。
- **ソロHでの3P:** パートナーのいない女の子とHを始めると、同じマップの別の女の子が二人目として加わり、3Pが選べるようになります。どの見物の子も3Pの女の子にできます。
- **衣装:** 夜のHでは、見物の子たちもお風呂上がりの服を着ます。入れ替えても、それぞれの子は自分の衣装のままです。
- **疲れた女の子:** Hで疲れ果てた子は、入れ替えで外れても疲れたままです。プレイヤーの方を向いて床に寝転び、反応やオナニー、ほかの子との絡みはしません。
- **好感度（ハート）0の女の子** は見物するだけです。

## 必要なもの

- AmanatsuLocation
- [BepInEx 6 (IL2CPP, bleeding edge)](https://builds.bepinex.dev/projects/bepinex_be)（一般的なMODパックに含まれているもの）
- 任意: オナニーのアニメーション用に、同じPCにインストールされた **Aicomi**

## インストール

1. [Releases](../../releases) ページから `AL_HWatchers-v1.0.7.zip` をダウンロードします。
2. ゲームフォルダ（`AmanatsuLocation.exe` のあるフォルダ）に展開し、`BepInEx/plugins/AL_HWatchers.dll` となるようにします。
3. ゲームを起動します。

## 操作

| キー | 動作 |
| --- | --- |
| F9 | 見物の子を一人呼ぶ |
| Shift + F9 | 見物の子を全員帰す |
| Ctrl + 右クリック（見物の子の上で） | その子のメニューを開く |

メニューでは、その子のハートの数が見られます。衣装や服の変更、オナニーの開始と停止もできます。ほかに、絡む相手と体位の選択、シーンへの入れ替え、3Pの女の子にする、帰す、もできます。メニューを開いている間は、ゲームの移動ツール（H画面の右下）でシーンではなくその子を動かせます。

※ ゲーム内のメニューは英語表示です。

## オナニーのアニメーション（Aicomi）

AmanatsuLocation にはオナニーのアニメーションがありません。初回起動時に、プラグインがお手持ちの Aicomi からアニメーションを変換し、`BepInEx/cache/AL_HWatchers_aicomi.bin` に保存します。このMODには Aicomi のデータは一切含まれていません。

- Aicomi はたいてい自動で見つかります。見つからない場合は、設定の **Watchers > Aicomi Folder** に Aicomi のフォルダ（`lib` フォルダがある場所）を指定してください。
- Aicomi がなくても、ほかの機能はすべて動作します。見物の子がオナニーしないだけです。
- `.bin` ファイルを削除すると、もう一度変換します。

## 設定

`BepInEx/config/AL_HWatchers.cfg` を編集するか、ConfigurationManager プラグイン（F1）を使います。

| 設定 | 初期値 | 内容 |
| --- | --- | --- |
| Bring Watchers Automatically | オン | Hが始まると女の子たちが見物に来る |
| Maximum Watchers | 3 | 同時に見物できる人数（1〜5） |
| Distance (m) | 1.8 | 二人からどれくらい離れて立つか |
| Excitement Speed | 1 | 興奮する速さ |
| Voice Volume | 0.4 | 見物の子の声の音量（ゲームの音量に対する割合） |
| Masturbation | オン | 興奮した子がオナニーする |
| Aicomi Folder | （空） | Aicomi が自動で見つからない場合の場所 |
| Couples Make Love | オン | カップルの二人が女の子同士で絡む |
| Join the Bukkake | オン | 見物の子がひざまずいてぶっかけに加わる |
| Swap Girls | オン | 見物の子をシーンと入れ替えられる |
| Second Girl in Solo H | オン | ソロHで二人目を加えて3Pできるようにする。Hが始まらない場合はオフに |
| Watcher Key | F9 | 見物の子を呼ぶキー |
| Detailed Log | オフ | シーンの出来事を BepInEx のログに書き出す（不具合報告用） |

## 注意

- 入れ替えた後でも、ゲームはシーンを始めた女の子とのHとして記録します。
- 69の途中で二人の相手を入れ替えると、体位が少しずれることがあります。いったん貝合わせにして戻すと直ります。
- 不具合を報告するときは、**Detailed Log** をオンにして再現し、`BepInEx/LogOutput.log` を添付してください。

## ビルド

.NET 6 SDK 以降と、一度 BepInEx を起動したゲームフォルダ（`BepInEx/interop` があるもの）が必要です。

```
cd src
dotnet build -c Release -p:GameDir="C:\path\to\AmanatsuLocation\BepInEx"
```

DLL は `src/bin/Release/net6.0/AL_HWatchers.dll` に出力されます。
